A ideia do projeto é criar um sistema rodado via terminal para facilitar a organização de partidas de futebol entre amigos. O foco é ser prático e rápido, funcionando da seguinte forma:

O organizador registra os participantes, confirma o valor da quadra, define o valor de rateio entre os participantes, confirma o pagamento e usando o sistema ele realiza o sorteio dos times. 

Informações da Partida: Após sorteio o organizador envia no grupo de whatsapp o time em que os jogadores irão participar, com endereço do local escrito e o horário marcado.

Resumo de Custos: O sistema mostra o valor total do aluguel da quadra e quanto cada um deve pagar ao organizador.
