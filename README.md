A ideia do projeto é criar um sistema rodado via terminal para facilitar a organização de partidas de futebol entre amigos. O foco é ser prático e rápido, funcionando da seguinte forma:

Cadastro Simples: O jogador entra com seus dados básicos para se identificar.

Informações da Partida: O sistema exibe o local da quadra, o mapa (endereço escrito) e o horário marcado.

Escolha de Times: O usuário visualiza quais times ainda têm vagas e escolhe em qual quer entrar. Se um time estiver lotado, o sistema bloqueia a entrada e sugere as vagas restantes.

Resumo de Custos: O sistema mostra o valor total do aluguel da quadra e quanto cada um deve pagar, dependendo de quantas pessoas confirmarem presença.
